# 013：训练场材质、主菜单画布及 3D 地图

以 012 用户截图和反馈为基线：训练场墙边及灯座出现眼睛/牙齿；4K 主菜单偏软；PDA 和地图现有文字清楚，但 3D 地图缩在左上角。保留 012 的中文字库、PDA、地图文字、字幕及 HUD 处理。

## 训练场的高清替换

将截图墙边的重复条带做透视展开，与锁定 ReMade 包内的 DDS 缩略图比较纹理结构和蓝色虹膜／暖色底纹。四张近同资产与证据同族：`5D6828F8`、`63940A62`、`9B687DF1`、`E65CDA77`。静态比较可定位候选族，不能只凭截图把当前关卡中的每次纹理绑定唯一归给其中一张。

构建器先核对 5,110 张 DDS 和代理 DLL 的完整输入清单，再移这四张的交付副本到 `optional/remastered-quarantine/`，不改变 DDS 字节、不移走原输入。活跃目录保留另外 5,106 张，对上述替代键不再有 DDS 或 PNG，[加载器](research/REMASTERED_LOADER.md)转回原图。曾与墙面共用该替换键的其他物件，也会在这些键上显示原版。验包从活跃目录和隔离目录重新拼回输入清单，拒绝额外加载文件。未用截图猜测配错的原始地图文件名。

## 主菜单与地图的光栅空间

- 主菜单启动在 `004A34E0` 选择 `004A1560(2)`，前端保持 `512×448` 逻辑空间；`004A86C3` 注册 `004A3390`，将菜单及背景画进私有目标，`004B7E57` 请求渲染，随后合成。012 增加的字库采样细节仍受旧目标像素数限制。013 在唯一分配调用 `004B9529` 提供 `1024×1024` 光栅，保留原布局、UV 取样区域与输入坐标。只对那个已核对标识和尺寸的私有目标，扩大已写 XYZRHW、裁剪和逻辑视口。没有更改字体轮廓或覆盖全局后处理。
- 012 提高地图/终端的光栅到了 `512×512`，但它只处理预变换坐标与裁剪。原生 3D 相机路径在绑定目标后通过 `004439E3 → 0062F180 → 0062EF30` 重新应用逻辑视口；例如把 `256×256` 覆盖写到加大的表面，就落在左上象限。013 在 `0062EF6E` 按已绑定私有目标换算相机视口；深度、XYZ 数据、原始相机描述符和其他目标保持原样。已是物理尺寸的视口、原生低分辨率模式不再缩放。视口设置器重放既有物理 scissor 时也不做二次变换。
- 不改字幕/PDA 管线、地图文本字格或术语。地图/PDA 私有目标的 512 光栅及原有直接文字批处理保留。

## 可复核证据

`tools/replay_display_013.py` 在隔离 x86 模拟中运行原版复合坐标函数、相机视口指令和编译后 ASI，于设备调用处记录参数。针对 012 与 013 比较 3D 视口、主菜单合成 UV、scissor、预变换顶点，并回退到 012 重放。离线结果不是实际 D3D 呈现或截图验收；用户手动比较训练场墙面、4K 主菜单、地图状态切换，并复核 PDA。
