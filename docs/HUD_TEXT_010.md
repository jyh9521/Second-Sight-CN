# 010：高分辨率 HUD 文字

## 用户反馈和改动

009 的用户截图显示：4K 对白字幕更清晰；左上教程提示（BS2447）和左下选中武器名“徒手”（BS445）字号仍接近原尺寸；图形设置文字依然偏软。三张截图是用户的游戏内观察，不代表 010 已通过实机验证。

- 教程提示使用 style 21，入队换行 0x62FEA7 / 0x62FEFB 和可见文字绘制 0x63009D / 0x630208 共用同一比例。
- 选中武器标签原生使用 style 18（原始 y=0.75），在 0x57B9D2 / 0x57BAF5 之间缩放测量、布局和绘制；原本有居中换行的分支在 0x57BA6E 同比增加宽度预算，保留每行容量。图标、右侧计数和其它 HUD 均不改。
- 两条路径按输出高度使用 max(1, height/720)，上限 4；两类字形分别在 4K 约 42、31 像素（提交几何近似，不是已测像素）。每段退出恢复原样式指针、字体序号及描述符。避免永久放大共享字体，同时保留动态按键、原版字幕和 FusionFix 的位置处理。

## 菜单清晰度

中文菜单和字幕共有自有字库，009 的 32 px 字格仍保留。菜单对象单独计算前端布局比例、测量与裁剪（0x4B73C0、0x4BF570 等），部分标签经过原生的多次描边与正文绘制（0x612D50）。截图的菜单字比字幕大得多，同一字格放大更多；这能解释一部分发软，但没有 GPU 帧证据可断言另有固定分辨率的中间渲染面。010 没有改菜单描边、设置点击区域、PDA、系统拉伸或原版英文字库，不标记该项已修好。后续应先按实际菜单帧确认采样与绘制目标，再做菜单专用改动。

## 内置修改器可行性（未实现）

固定 FusionFix 的 `DeveloperOverlay.ixx` 有 Ctrl+F10 调试覆盖层，只注册 Debug/Info；当前 ASI 导出是 AsiSettings_GetApi 与 InitializeASI，没有外部 ASI 注册此调试页的导出。因此建议独立可选 GameplayTweaks ASI，而非覆盖官方 FusionFix 二进制或与汉化状态绑定。可复用类似的 D3D9 UI 设计，但窗口消息、帧入口、设备重置、鼠标输入优先级和 F1 冲突要与固定 FusionFix/高清版共同核对。

拟优先做默认关闭的无限生命、无限超能力两个开关，只对玩家且不保存到存档；在开关联动前单独验证当前值/上限/扣减与剧情状态。隐身要先区分敌人感知和单纯隐藏玩家模型，不用后者冒充前者，重点验证剧情触发、已警戒敌人及关闭后恢复。菜单打开时应吞掉用于点击的输入，避免同时攻击；关闭后恢复。010 不包含修改器代码、快捷键或空开关。

## 验证边界

[回放工具](../tools/replay_hud_text.py) 执行原版教程入队/绘制和选中武器两种分支，结合实际编译 ASI 的作用域函数。输入使用当前语言包的 BS2447 和 BS445，动态按键为夹具给定的“鼠标左键”；纹理提交、纹理句柄、栈保护调用是受控边界。640×480、1920×1080、3840×2160 下分别检查文本完整、锚点在屏幕内、换行和显示使用相同字号、原字体状态和样式表还原。

009 基线 1/3、退出 1，010 修改 3/3、退出 0；另一个映射副本恢复七处原字节后，仍是 1/3、退出 1。集成静态审计 27 条 FusionFix 写区间与 32 处补丁检查区间不重叠。离线结果不代替实际 HUD 视觉验收。完整绝对命令和独立文件回滚见本地 `build/feedback-010/verification/VERIFICATION.txt`。
