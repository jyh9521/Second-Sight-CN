本页记录固定 GOG PC EXE 的离线证据与补丁契约，不代表实机验收。
EXE SHA-256：`4092a8d1fb042dffe9fb95e2185f32cb80390299145e8d453a5e909a06d35fda`，大小 5,484,544。
机械地址、原字节、替换字节和逐 ID 消费者见 `assets/full-text-contracts.json`。

## 已验证：6 页字体可扩展为 6142 个有效字位

原路径用 6 个描述符、每页 16×16 字格。维持描述符数量和 16 px 字格，将 DDS 改为 512×512、32×32 字格，总计 6144 位；178、184 仍保留给原换行逻辑的特殊意义，所以可用 6142 位。

绘制循环 `0x612595–0x6125FC` 的七处整数运算分别更新为 page=`id>>10`、cell=`id&1023`、column=`cell&31`、row=`cell>>5`。保留有符号修正形状，修改前逐字节比较，原始字节不符即整批拒绝安装。原十进制字符解析支持四位索引；locale 编码仍为 marker `0x1F` + 四位十进制，所有可见字符都编码，避免紧随数字被原解析器继续吞入。

**UV 并非固定 4096 归一化。** `0x40DBAA–0x40DBE0` 从纹理元数据 `+0x18/+0x1A` 读取实际宽高，并计算 `1/(dimension*16)`；`0x60FEC0` 等顶点路径使用 `(uv+8)*scale`。原 UV 单位是像素×16，因此保留左边 `column*256`、右边 `+248`、顶部 `row*256`、底部 `+256`。512 页只需真实尺寸变化；把 UV 格宽 256 改成 128 会错误压缩采样范围。最后一格 UV 上界 8192，仍位于有符号 16 位范围内。

`0x610A80` 测量路径使用描述符内 16 px 字高/推进量，不计算纹理页/行列；没有照抄绘制 patch 到测量函数。描述符数量仍为六，资源名不变，DXT3 payload 262144 字节，完整 DDS 262272 字节。

## 已验证：长文本必须按消费者分档

255 不是 BS 文件格式限制。它来自 `0x4BEA70` 的某个 UI 编辑框拷贝，另有 HUD 与终端缓冲，不可据此全局扩大。

- `0x62FE80` 的 HUD 入口拒绝输入长度 ≥511；后续 wrap 输出复制到 512 字节全局槽，`0x6301A0` 显示路径又复制到 512 字节栈。仅搬走全局槽仍会溢出栈。
- `0x639BE9` 将另一 wrap 结果截取至 256 字节对象字段；其 source ID 未证明，仍保守处理。
- 菜单键名缓存经 `0x53FDE0` 输出 64 字节引用格式，单原始键名仍限定 27 编码字节。

### 自有可写 wrap

在 `0x611C70` 首个完整 6 字节指令 `81 EC 04 02 00 00` 安装 cdecl `char*(const char*,float)` hook。原 ASCII 路径调用 trampoline；已编码文本进入自有字符串，测宽仍调用 `0x611940`（cdecl、float 返回 ST0）。每个 token 原子推进，按 glyph 提供换行机会，ASCII 单词尽量保持完整。超长 ASCII 单词逐字符切分，不拆 token。

输入上限 4095，输出上限 8190；8 个独立轮转输出与键名展开缓冲分离。返回可写存储，因为邮件滚动器确实原位写 NUL 选择可见行，而不是持有不可修改的翻译常量。

额外每行编码上限 250：纸张显示分支 `0x5E2BFB` 逐行复制到 256 字节栈、`0x5E2C0F` 加终止符。像素宽度不能证明编码行长（一个字为五字节），所以双重限制同时生效，仅额外换行，不裁删正文。非正宽度保留自有完整副本；已证明纸张调用的宽度为正。

### SETU 物件文档

资源头 `0x90/0x94/0x98` 分别给出表位置、数量、72 字节记录步长。记录 `+0x34` 是 BS 起始 ID，`+0x0C` 是页数。`0x549609` 按 72 字节步长调用初始化 `0x548D60`，其 `0x548DA0` 调 `0x5E28F0` 把记录指针保存到物件 `+0xBC`。显示 `0x5E2813/0x5E2AF7` 取记录 `+0x34` 加当前页 `0x971D40`，直接 wrap；翻页上限 `0x5E2D9F` 读取 `+0x0C-1`。

这不是扫描到一个相同整数就判定引用：档案表边界、步长、初始化、字段读取和翻页计算相互闭合。逐资源 SHA、记录位置与 ID 已存机械 profile，不包含原始资源正文。覆盖医疗记录、现场公告、第一关关卡文档、泽纳病历及 5683/5684 两页日记。低位标志 bit0 选择逐行居中路径，因此保留上述 250 行编码限制。

### 终端 5922、5924、5926

`0x893A68 + index*44` 记录的 +4 是正文 ID。`0x5429B0/0x542A10` 各分配 1024 字节局部缓冲，传给 `0x5D0620/0x5D06D0`，`0x5D0580` 按容量组合内容，然后调用新的 wrap。这三项记录 count=1、追加常量为空，因此正文分档 1023，不是 4095。原滚动器对可写 wrap 输出扫描换行、写终止符，没有复制全文回 1024 栈。

### 复合终端 3644–3648

`0x89363C` 记录 count=5，把五段 BS 正文用四个双换行连接。全译文合计 1198 编码字节，原 caller 1024 会截断；不能只放宽单段限制。

仅将 compose 调用 `0x5D0643/0x5D06FB` 替换为 cdecl 裸桥接（原完整字节分别 `E8 38 FF FF FF`、`E8 80 FE FF FF`），三个参数及栈清理方式不变，返回的自有指针分别写到调用者接下来使用的 ESI/EDI。函数原先保存在栈上的 ESI/EDI 不动，返回时仍正常恢复。自身 x86 host 用 owned callback 验证两种桥接的参数和返回寄存器，不执行原游戏 composer。

仅精确记录地址、count、五个 ID、五个 separator 指针均匹配，且每个源 BS 与 pack 原文完全匹配时启用；五条 BS 全部保持原指针。目标五段完整拼接到独立轮转字符串后直接进入 wrap，不经过 1024 目标。其它 composer 记录调用原函数并继续使用原目的地址。构建与 native pack parser 同时验证五段齐全、总字节 <=4095。

## 占位符保真

全 BS 扫描中标准 printf `%s` 位于 4511 `Mode: %s`。保持字节 `25 73`，不作为两个字形编码；native pack 解析也按该原文/ID 验证其恰好一处存在。消费者尚未证明，不更改其保守预算。`%1..%9` 是另一套 `0x43E310` 数字模板，不能当作 printf。

4478 在 `0x557519` 使用 512 字节模板目标，参数 %1 来自 BS5224、%2 来自 `0x53FDE0` 引用键名，分别上界 10/59，VT2 再上界 59；精确预算取代每槽127的泛化估计。BS5224 构建和运行时都强制 <=10，避免只假设当前译文长度。

### 已证教程模板与 HUD 后置拷贝

21 条原生/VM 教程已独立定位参数产生处，profile 保存每槽 guard。按住/按下 BS601/5224 均 <=10，双键显示 <=59，移动轴标签 <=27；不是把所有 `%n` 一概按127估算。VM 原生 `0x624930` 的目标为256，最大当前2909展开232；3336 的格式器为512，当前展开323。因此源模板仍 <=255，而仅3336的展开界为510（符合后续 HUD 入口）。其它已证模板仍用255展开界。

新增 wrap hook 在原 HUD 调用返回地址 `0x62FEC7` 检查实际 wrap 输出 <=511。若极端像素宽度使新添 LF 超出余量，则保留完整已展开输入，取消新增换行并记录日志，不截字符、不扩大512原缓冲。通常323字节具有188字节换行余量；此边界保护不代替实机版式验收。未知2912与Blocks作弊提示没有因猜测参数为单字符而放宽。

## 两条独立硬编码提示

`assets/exe-text-contracts.json` 记录完整push、原串与固定EXE身份；译文在独立 `exe-texts.json`。SLP2为这类文本增加单独计数与记录，不借用BS编号。运行时核对原串，和其它改动一起逐字节预检后，将push中的指针改指向pack持久译文。原磁盘EXE和原字符串字节不变。

- `0x4B6DD0: 68 A8 AA 7D 00`：Quick scroll → 快速滚动。4B6340把指针存object+128；4B76F0的四个footer槽步长255，前缀VT4和空格及NUL占4字节，原串预算251。当前20编码字节，构建与运行时更保守限定64
- `0x576A14: 68 80 C2 7D 00`：Button inoperative → 按钮不可用。639B50先wrap再strncpy到256槽，当前25编码字节；64字节上限且拒绝控制码，使自有wrap即使逐字节增加LF也低于128，保留NUL余量

这些消费链已静态证实，但原始发行资产暂未发现激活两个提示的参数：47处直接控件caller未带80000，已恢复120条SETU回调记录未含index32。覆盖是防御性处理，不声称用户已触发。旧主机暂停菜单和CONTROLS路径不属于PC已识别PDA暂停路径，未据名字直接增加新钩子。
