## 输入身份

- 平台：Windows PC、x86；当前适配 GOG 版本。EXE 版本资源为 `0,10,0,0`；商店修订号及销售地区未独立确认。
- 英文资源包含 en-GB 主表与 en-US 变体；这不是对其他地区发行版的兼容声明。
- EXE SHA-256：`4092a8d1fb042dffe9fb95e2185f32cb80390299145e8d453a5e909a06d35fda`。
- BS 成员路径、大小、英美双 hash 由 [source-variants.json](../assets/source-variants.json) 唯一维护；PDA、UI、EXE 提示及字节契约见[技术说明](../TECHNICAL.md)和 `assets/` 中对应契约。
- 字体身份由 [font.json](../locales/zh-CN/font.json) 维护；当前为 Source Han Sans SC Regular 2.005。构建器校验字体及许可 hash。
- 全安装目录的只读清单在本地 `build/baseline-adoption-20261117/input-inventory.json`。清单记录每个文件的相对路径、字节数、SHA-256 和角色，**不是已经实现了全输入构建前置拒绝**。当前构建仅对 EXE 和实际提取成员等已建立契约的输入作强校验；G0 全输入拒绝的补齐仍待进行。

## 数据契约适配

当前 JSON 加载仍使用标准 `json.loads`，尚未实现通用契约要求的重复对象键拒绝；这是待补的 G1 检查，不因已有重复 ID 拒绝而视为完成。

保留现有 `schema: 1`、`poc.json` 入口及各 JSON 分目录；不复制基准示例目录，不为匹配模板强制迁移已有 ID。

| 通用语义 | 当前项目字段/约束 | 差异及处理 |
|---|---|---|
| 稳定 ID、资源 | `bs` 整数；`pda` 页/行/段；`exe` 契约 ID；图像资源名 | 用组名限定 ID 命名空间；共享源文本不合并不同上下文 |
| 源文指纹 | `source` 或 `source_sha256`，二选一 | 现有 hash 是原 **CP1252 原始字节**，不是通用示例的 UTF-8 hash。`bind_sources` 核对原字节；不重写旧指纹 |
| 目标及处置 | 非空 `target`；569 槽在 `coverage.json` 有保留理由 | 现有 schema 没有完整 disposition 枚举，不把有目标文本等同审校完成 |
| 语境/角色 | `context`、`text_kind` | `ui/objective → other`；旧 `narrative → story_or_dialogue`，仅供标点例外。尚未逐条复审角色；混合内容应按证据拆 span，不能因文件名 story 自动豁免 |
| 术语 | `terms` 引用 glossary 的 active/proposed 状态 | active 术语不等于整条译文经过审校 |
| 控制码 | `source_tokens` 或源串提取 | VT+按钮码、LF/TAB、编号模板及特定 `%s` 保持顺序；未知控制码拒绝 |
| 审校/运行验证 | 旧自由文本 `status`、历史报告和用户截图 | 尚无源文+目标+候选绑定的逐条审校/运行台账；既往结果不自动导入新枚举 |

中文规则只以 [STYLE](../locales/zh-CN/STYLE.md) 为准。`style.json` 仅保存角色映射与策略路由。逐句检查由通用语言策略和 `audit_locale_policy.py` 的原生控制码适配组成；可见投影保留 LF/TAB，不把显示行当作逻辑句子。检查只报告，不自动删除点号。动态模板填充后的完整语义仍需审校/运行观察。
