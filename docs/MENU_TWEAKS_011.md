# 011：菜单清晰度与独立 F1 修改器

## 菜单

用户的 4K 画面中字幕更清晰，但前端图形设置的中文仍偏软。011 只在两个确认的前端调用点把四次偏移描边改为一次右下影子，保留原正文、颜色、宽度、坐标和样式还原。仅对解析得到有效自有字形标记的文本生效；纯 ASCII、原本无描边的标签和其他调用者继续走原路径。字库、共享字形度量、字幕和 PDA 绘制链未改。此改动减少描边叠影，不声称切换了渲染分辨率或消除了整个菜单的扫描线效果。

| 前端调用点 | 作用 |
|---|---|
| 0x4B758A | 前端有描边的静态菜单标签 |
| 0x4BF717 | 前端值／选项文字中的有描边分支 |

## 可选模块

`SecondSight.GameplayTweaks.asi` 使用原加载器从 `game/scripts/` 加载，不替换 FusionFix。窗口是游戏自有进程的独立 Win32 工具面板，不接管 FusionFix 的 WndProc、Present 或 Ctrl+F10。仅游戏或面板在前台时响应该次 F1 按下；关闭面板不关闭所选功能，退出游戏清空开关。三个功能默认关闭，不向存档写配置。游戏可能把当前生命等游戏状态按原逻辑保存；这里不改变存档格式。

| 开关 | 已核对的原版语义与边界 |
|---|---|
| 无限生命 | 只对主玩家，普通伤害主／备用路径保留判定和动作但不扣生命；有效游戏更新补满受伤生命。不复活已死者，也不屏蔽脚本直接设定的死亡 |
| 无限超能力 | 只对主玩家，正常更新补满能量，8 处已核对消耗写回保持满量；不自动解锁超能力 |
| 隐身 | 当主玩家是感知对象时，原生 AI 感知入口返回未感知，不隐藏模型、不改阵营。已有警戒状态、剧情强制跟踪不保证消失 |

适配只允许固定的 GOG EXE 与 FusionFix 文件身份，12 处原字节全部核对后才写入内存。主玩家由原生主上下文取得（`0xA1D604`、`+0x20`），不是当前控制的 NPC 投影。生命字段为 actor `+0x208/+0x20C`，能量为主上下文 `+0xEE0/+0xEE8`；仅原生更新线程在已证入口改值。伤害写回 `0x5DFF20/0x5E197F`，感知 `0x48D7C0`，更新 `0x545430`。精确消耗区间及原字节只以[原生区间表](../src/gameplay_tweaks_sites.h)为准。

## 启用与测试

此处描述 011 的历史出厂状态。012 的本地更新及以后版本默认加载，使用同一脚本切换。

手动关闭测试游戏；在 011 测试包根目录用 PowerShell 执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Set-GameplayTweaks.ps1 -Mode Enable
```

随后由用户从包内 `game` 目录启动游戏。在无边框模式下按 F1 打开并勾选功能，再按 F1 关闭；重新打开可取消勾选。退出游戏后执行同一脚本的 `-Mode Disable` 恢复默认安装；`-Mode Status` 仅核对文件。包内可选副本和其他组件不被移动或改写。菜单清晰度修正在汉化模块中，不依赖启用修改器。

建议用同一 4K 分辨率先比较 010 和 011 的图形设置选中项，再浏览长 PDA 页、过场与独白字幕。在无边框模式下检查 F1、鼠标、恢复游戏输入以及与 Ctrl+F10 的切换；进入敌人可见区域测试隐身前后，再用普通伤害和已解锁的超能力分别检查开关。已警戒 NPC 另行测试，不拿它代替初次感知测试。

## 验证边界

[离线指令回放](../tools/replay_menu_tweaks.py)在图像副本执行原版及实际构建模块。两处菜单路径的中文绘制由 5 次变为 2 次，ASCII 与直接共享入口仍 5 次；两处生命写回、8 处能量写回、玩家／NPC 感知、关停以及隔离字节恢复均有对照。GPU 提交、AI 几何查询和游戏更新里不相关的子调用为固定夹具边界，不是用户可见验收。

[静态共存审计](../tools/inspect_integration.py)核对固定 FusionFix 27 条 pattern 写区间与本地化、修改器写区间互不重叠。CI 用合成宿主验证 x86 ASI 导出、F1 边沿、分支编码、非游戏宿主拒绝及可选安装／恢复；CI 不包含原版游戏资源。实际按键／鼠标焦点、敌人警戒及画面清晰度由用户验收。
