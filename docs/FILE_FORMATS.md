# 文件格式记录

基线为[技术说明](../TECHNICAL.md)中的 GOG PC 文件。以下已验证结论来自全量目录扫描、指定资源读取和静态加载代码；游戏对重建结果的接受情况仍待用户验收。

## P4CK 封包

扩展名为 `.pak`，所有整数均为小端。初始扫描覆盖 258 个封包，24,930 个目录条目。

| 位置 | 类型 | 含义 |
|---|---|---|
| `0x00` | 4 字节 | 魔数 `P4CK` |
| `0x04` | u32 | 目录起始位置，相对文件开头 |
| `0x08` | u32 | 条目表字节数；除以 16 得到条目数 |
| `0x0C` | u32 | 文件名池字节数，不包含条目表 |

目录先放 16 字节条目，再放 ASCII、NUL 结尾的文件名池。每条记录由四个 u32 组成：

1. 文件名偏移，相对目录起始位置。
2. 载荷偏移，相对文件开头。
3. 载荷长度。
4. 未知字段；本次原版扫描观察值均为 0，不能据此假定其他版本无意义。

本次所有封包的“目录起点 + 条目表长度 + 文件名池长度”等于文件长度，载荷位于目录之前。解析器校验边界、名字终止符和记录范围，不把畸形记录静默截短。

### 重建约束

- 保留目录顺序、未修改成员及未知字段。
- `anim/animg2.pak` 有 5 处同名成员；替换工具必须处理名称歧义，不按名字去重。
- 各包载荷对齐并不统一。当前 arcade 追加探针对新载荷用 2,048 字节对齐、新目录用 16 字节对齐；这只是离线实验策略，不是已证明的通用引擎要求。
- 无改动回写应逐字节一致；变长回写可以追加新成员数据，再更新对应记录与目录位置，旧数据仍可留在副本中。

## BS 主文本表

已发现 `data/strsspxe.bs`、`strssnxa.bs`、`strsspxf.bs`、`strsspxg.bs`、`strsspxi.bs`、`strsspxs.bs`。它们出现在 `pak/arcade/l_101.pak` 和 `l_103.pak`，两包内同名资源逐字节相同。

| 部分 | 结构 |
|---|---|
| 偏移表 | 6,526 个 u32，长度 `0x65F8`（26,104）字节 |
| 字符串池 | NUL 结尾的字节字符串；偏移相对 BS 文件开头 |
| 别名 | 多个 ID 可指向同一字符串偏移 |

EXE 加载器静态代码也以 `0x65F8` 为偏移表长度并加上加载基址，与数据结构一致。英文 `strsspxe.bs` 为 237,400 字节，SHA-256：

```text
e72b56066e8b68fb23ac2833b58376a18a506503e02e83864727eef1fbc03a7d
```

已有 6,425 个非空 ID、5,484 个不同非空字符串；这些数量不是已完成的翻译清单。原始文本中观察到 `0x09`、`0x0A`、`0x0B`，保持这些控制字节，暂不为其全部调用场景赋予未经验证的含义。

当前解析器由首偏移识别表长度，实验保留 ID 0 的锚点。探针只追加新字符串并改写 ID 850 的偏移，不拆改其他共享 ID。未来通用导入器需要明确表长来源、编码、别名和控制码规则，不能直接把编辑态 UTF-8 当作游戏编码。

## PDA 资源

`data/pdaps_[aefgis].raw` 包含任务目标、人物、武器等资料，是结构化资源而非普通文本文件。每个后缀在 17 个剧情包中重复；当前 a/e 内容相同。

`tools/pda_resources.py` 已实现离线解析与追加/重定向重建。32 字节头部由 8 个 u32 组成：页表、索引表、图片描述符表、标识符表的偏移，以及各自数量。页条目为“行数/行表偏移”；行条目为 u32 段表偏移、i16 段数、u16 元数据；段条目为 u32 值和 i32 标签。文本段的值指向 NUL 结尾字节串，特殊标签与图片引用不当作文本改写。

稳定定位采用 `pNNN.rNNN.sNNN`，保留对应指针字段偏移；校验表边界、重叠、字符串终止符、源 hash、共享字段及控制标记。无改动重建返回原字节，变长替换追加新字节再重定向字段，未选择的段保持原值。

初始 PoC 选中 `p055.r000.s000` 至 `p055.r003.s000`，即一个 Isolation 任务页的四条文本；当前目录已扩展至 68 页全部 447 个非空显示段。语言包携带字段偏移与预期原文，模块在游戏解析/重定位后替换指针；不安装离线重建 raw，也不改 PAK。游戏端显示、长段、分页和滚动仍待用户验收。详细结构、原始偏移和缓存路径证据见 [PDA 格式研究](research/PDA_FORMAT.md)。

## 字体资源与特殊字形

| 名称 | 尺寸 | 格式 | 本次份数 |
|---|---|---|---|
| impact | 256×256 | DXT3 DDS | 19 |
| book | 128×256 | DXT3 DDS | 20 |
| booklight | 128×256 | DXT3 DDS | 19 |

每种名称的多份资源 hash 一致。EXE 同时引用 fontcaps 和六页 jpnfont，但本次全部 PAK 成员名中未找到对应资源。PC 字体加载器会把 `.raw` 名称转换为 `.dds`，不能只按字符串后缀判断格式。

原特殊文字路径使用“逗号 + 十进制字形编号”。当前识别点改为 `0x1F`，每个可见译文字符用前导符加四位十进制编号表示；字集分配范围 0～6143，避开 178、184，拒绝紧随编号的裸数字。源绑定 VT+`1..K`、LF/TAB、`%1..%9` 和特定 BS4511 的 `%s` 原样作为受保护 token，不收进字形集。

当前六张图集使用固定思源黑体，均为 512×512 DXT3 DDS，每页 32×32 个 16 px 字格，完整文件 262,272 字节，资源名 `textures/localization/page0.dds` 至 `page5.dds`。七处原生分页/行列运算同步适配，UV 保留像素×16 单位并按真实纹理尺寸归一化。总 6,144 格，可分配 6,142 格；当前目录需要 1,958 字形。原版的 16×16 网格和 001–005 的 256×256 图集仅属历史布局，不能混用新运行时的资源校验。

BS 不是固定 255 字节格式：255 来自特定 UI 消费者。当前默认 255、已证终端 1,023、已证长文/受限延迟记录 4,095，模板展开另算，PDA 为 1,800；纸张每行还限 250 编码字节。详细 ID 和依据见[全量容量契约](research/FULL_TEXT_CAPACITY.md)。

## 独立 UI 位图

`locales/<locale>/ui-textures.json` 保存文字、字号、位置及框线；`assets/ui-texture-contracts.json` 保存资源名、源 SHA-256、长度、镜像数、尺寸、颜色及垂直翻转契约。当前唯一项为 `textures/misc/nse_tv/loading.dds`：256×64 DXT3、16,512 字节、两份源镜像，按原 UV 方向存储。

位图由同一固定字体独立生成，不读取原图像素进行改绘，也不修改 PAK 或 ReMade 输入。当前资源集合为六张字库加此 UI 位图，共七项；这不意味着所有原始图像文字均已汉化。PC 版权页的 `legal_english512.dds` 保持原样，BS313/314 不驱动该页。

## SLP2 语言包与 SLP1 读取兼容

`tools/build_locale.py` 生成 `locale.bin`，是本项目格式，不是原版格式。所有整数为 u32 小端；字符串和二进制块带 u32 长度前缀，不额外带 NUL。当前生成 SLP2，运行时也识别不含 EXE 记录的 SLP1 头；读取兼容仍受当前字体尺寸及消费契约校验，不保证任意历史包可混搭新模块。

| 顺序 | SLP2 内容 |
|---|---|
| 头部 | `SLP2`，依次 BS 数、PDA 数、资源数、EXE 文本数 |
| BS 记录 | 原 BS ID，长度前缀原文字节，长度前缀标记编码译文 |
| PDA 记录 | 重定位结构内的指针字段偏移，长度前缀原文，长度前缀译文 |
| EXE 记录 | 已审计契约 ID，长度前缀原文字节，长度前缀编码译文 |
| 资源记录 | 长度前缀 ASCII 资源名，长度前缀 DDS 数据 |

SLP1 头只有 BS/PDA/资源三个计数，EXE 数视为零，后接 BS、PDA 和资源记录。SLP2 的 EXE 计数是追加的第四计数，但记录放在资源之前，不可按计数顺序误排载荷。

当前 EXE 项由 `exe-texts.json` 和 `assets/exe-text-contracts.json` 管理：快速滚动对应 PDA 页脚、按钮不可用对应交互反馈。先验证固定 EXE、源字符串和完整五字节 push，再将立即数指针指向模块持有的持久译文；不改原字符串或磁盘 EXE，不新增函数钩子。两项各限 64 编码字节；消费者与局部容量已证，实际 PC 触发可达性尚未完全闭合，作为防御性覆盖而非已见实机修复。

运行时接受六张字体图集，或六张图集加一张已知 UI 位图；资源必须按规定顺序、名字、尺寸及 DXT3 头部匹配。解析器拒绝重复 ID、坏长度、截断、非法 token、超预算及尾随字节。原文用于替换前校验，输入/产物 hash 在 `manifest.json`；包不包含完整原始 BS/PDA/PAK。

manifest 的 `bs_binding` 区分直接绑定、组合终端和待定位旧文本；`targets` 冻结构建使用的译文，回滚验证不读取后来变化的源码目录。当前 BS 总数不能直接用作 `expected-direct` 日志计数。

## 其他文本线索

`csinfo.txt` 是场景/动作清单，不是可直接翻译的字幕文件。VM 脚本、纹理文字和主文本引用关系尚待进一步核对；不把所有含可读字符串的文件自动列为可替换文本。

实现入口见 `tools/assess_resources.py`；初始证据、静态地址和覆盖范围见[可行性评估](ASSESSMENT_2026-11-17.md)。

## 编辑数据补充

文本的 `text_kind`（ui/objective/narrative）和 `terms`（术语 ID 列表）属于编辑元数据，不直接进入运行时记录。各 locale 的 `style.json`、`glossary.json`、`font.json` 分别提供标点策略、术语状态/定位及字体身份；manifest 记录这些源文件的 hash。当前英文简介页为 p002，短任务页为 p055；用户可见反馈见[编辑基线](FONT_AND_EDITORIAL.md)。

## 005 目录与传输扩展（历史）

当时 SLP1 布局不变，数据为 832 条 BS、447 条 PDA，仍有六张图集。源码由 poc.json 的 catalogs 声明分文件；新增记录使用 source_sha256 与 source_tokens，构建时绑定固定源资源，不发布完整英文池。manifest 新增 targets 快照与 coverage 统计，回滚验证读取冻结的目标值。

005 编码器保留源绑定的 VT+1..K、LF/TAB 和 %1..%9。图集只收集可见字符，不把 opcode/模板参数作为字形。BS 传输和按键展开后均限制255字节；物理键名及movement/mouse标签最多27字节；PDA展开后最多1,800字节。详细原生分档规则及五个新增接入点见[文本契约](research/TEXT_CONTRACTS_005.md)。此前四样本、450字节与 Noto 描述属于初始 PoC 历史。当前容量与 SLP2 以本页前述章节和全量容量契约为准。
