# 中文 PoC 手动测试

**PoC 001 本地测试包已完成离线构建；游戏内显示与 FusionFix 共存尚未验收。** 本页是用户手动测试清单，不是游戏内测试报告。当前包目录为 `dist/poc-zh-CN-001`；本轮 49 项合成测试、离线宿主和 299 个包内清单文件检查通过，原安装 305 个文件未变。

自动化只构建、复制和离线校验文件，不自行启动游戏。此前一次隔离副本启动在截图前中止，没有形成实机通过结果。后续游戏操作均由用户执行并反馈。

## 本次样本

| 类型 | 数据范围 | 可以检验什么 |
|---|---|---|
| 菜单 | 21 条 BS，例如 ID 850“新游戏”、899“选项”、872“字幕” | 基础中文显示、选中状态、标签边界 |
| 剧情候选 | 11 条 BS，包括“我在哪里？”“让我帮你。”等 | 先确认对应场景，再检验字幕显示与时序 |
| PDA | `p055.r000.s000`～`p055.r003.s000`：任务目标 / 隔离 / 逃离。 / 离开隔离室。 | 同一个 Isolation 任务页的标题与短正文 |

剧情候选尚未完成场景映射；遇到其他英文字幕是预期现象，不代表全量翻译失败。PDA 样本不是四个页面，也尚未覆盖长段落、分页或滚动。

样本来源为 [poc.json](https://github.com/jyh9521/Second-Sight-CN/blob/main/locales/zh-CN/poc.json)。构建器拒绝带控制码或 `%` 的条目，当前样本不验证格式化占位符和显式换行。字体采用六张 256×256 DXT3 图集，标记编码是内部传输格式，不应直接显示成数字或乱码。

## 测试前

1. 按[构建说明](https://github.com/jyh9521/Second-Sight-CN/blob/main/BUILDING.md)生成隔离包，并完成合成测试、自有离线宿主与完整性检查。仓库根目录的校验命令为 `python -X utf8 tools/stage_poc.py --verify --out dist/poc-zh-CN-001`；它不启动游戏。
2. 测试包内 `game/` 是本地副本，`package.json` 保存打包时的文件 hash；不要直接覆盖原游戏目录。校验应在手动测试或修改配置之前执行。
3. 记录测试包标识、原版 EXE hash、FusionFix 版本、配置、分辨率和窗口模式。初次测试仅使用固定 FusionFix，不混入尚未评估的 Nexus 模组。
4. 包内 `game/profiles/` 初始为空，构建器不复制原存档。仍请备份个人存档并记录位置；本轮没有实测所有用户目录/注册表状态，不把新目录等同于已验证全部存档隔离。
5. 用户手动双击包内 `game/secondsight.EXE`，不要使用指向原安装的快捷方式。自动化构建与 `localization_host.exe` 均不承担启动游戏这一步。

当前构建若包含 `Set-GameplayTweaks.ps1`，F1 菜单默认随包加载；三个功能仍需手动勾选。关闭游戏后可用脚本的 `-Mode Disable` 停用。

## 第一轮：菜单与启动

- 检查“新游戏”“选项”“字幕”等选中样本；保留完整画面截图，不仅裁出几个字。
- 检查文字是否缺字、模糊、被截断或显示标记数字，菜单选中与切换是否正常。
- 检查未翻译英文、数字、普通逗号和原有按键提示是否仍正常；样本只替换有限 ID，不期待菜单全部中文。
- 保留 FusionFix 原功能与当前配置，记录异常是否随设置变化。

出现加载失败或崩溃时先退出测试副本并保存日志，不把单次窗口出现记为通过。

## 第二轮：剧情字幕与 PDA

- 用户在实际剧情中定位候选字幕，记录场景、角色、存档位置、触发操作和出现/消失时机。没有看到候选句时记“场景未定位”，而不是直接判定该 ID 已失效。
- 打开对应 Isolation 任务页，核对四条中文；进入/退出 PDA，切换页面后重新打开，观察缓存和指针替换是否持续生效。
- 分别保存字幕和 PDA 截图。菜单成功不能替代这两类验收。
- 长字幕、长段 PDA、分页/滚动、控制码和按键占位符需要后续专门样本，本轮不勾选这些项目通过。

## 日志怎样判断

模块日志位于测试包的 `game/scripts/SecondSight.Localization.log`。以下是代码中定义的诊断消息，不代表当前已观测到这些运行结果：

| 消息 | 含义 |
|---|---|
| `HOOKS installed; ... runtime acceptance pending` | 预期字节检查完成并已写入模块挂钩；仍需用户观察画面 |
| `FONT mode=1; descriptor refreshed` | 执行过字体模式适配路径，不证明图集已经显示 |
| `ATLAS read served` | 模块响应过图集资源读取，不证明最终渲染正确 |
| `BS substituted=32 expected=32` | 32 条 BS 原文匹配并替换指针；不证明已到达所有使用场景 |
| `PDA substituted=4 expected=4` | 所选四个字段匹配并替换；需结合对应页面截图 |
| `IDENTITY REJECTED; no game-memory access or writes` | 宿主身份不符；在离线宿主中是预期，在目标游戏中应检查版本/路径 |
| `HOOK CONFLICT at ...; no patches installed` | 目标位置不再是预期原字节，模块拒绝安装；记录模组列表和加载顺序 |

计数少于预期时保留完整日志和实际语言设置，不随意更改原文件绕过检查。`HOST PASS` 只证明离线测试宿主完成检查，不能代替上述游戏日志或画面证据。

## 退出与恢复

PoC 修改的是进程内指针与代码，退出游戏后这些内存修改结束；原 EXE 与 PAK 不应被写入。**先由用户手动关闭测试游戏**，再从测试包目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Disable-Localization.ps1
```

脚本核对 ASI hash 后把 `game/scripts/SecondSight.Localization.asi` 改名为 `.asi.disabled`，保留 FusionFix，不启动或结束游戏。禁用模块后，原始包完整性校验会因 ASI 已改名而报差异，这是文件状态变化，不是实机结论。

禁用只撤下汉化模块，不会撤下 FusionFix，也不会删除新建的测试存档。由用户手动启动该副本检查无汉化行为；需要纯原版时使用始终未改动的原安装。不要把“禁用汉化、保留 FusionFix”写成“已恢复纯 GOG 原版”。
