# 《Second Sight》简体中文汉化

PC 版《Second Sight》的简体中文汉化项目。保留原版 FusionFix，以独立本地化模块和结构化语言数据实现中文支持，也为其他语言保留可复用工具。

**当前处于中文最小样本开发阶段，尚未发布可玩的汉化补丁。** 独立模块、语言包与 **PoC 001 本地测试副本已完成离线构建**。先由用户验证菜单、剧情字幕和 PDA，再推进全量翻译。离线检查不代表游戏内显示或 FusionFix 共存已通过。

## 从源码验证

需要 Python 和用户自行提供的原版游戏文件。以下命令只运行不含游戏资产的合成测试：

```powershell
python -X utf8 -m unittest discover -s tests -v
```

中文样本、x86 ASI、离线测试宿主和资源探针的命令见[构建说明](BUILDING.md)。PoC 通过运行时指针提供译文，不改写原 PAK；本地生成的完整资源及隔离游戏副本不作为发行包提交。

本次本地测试包位于 `dist/poc-zh-CN-001/`，含测试说明与禁用汉化脚本；完整副本不上传。构建前后原安装 305 个文件保持不变，本轮没有启动游戏。

样本的实际场景、日志和恢复方法见[PoC 手动测试说明](docs/POC_TESTING.md)。11 条剧情文本仍属候选，尚未完成场景对应，不能视为已有 11 条字幕实测。
